  Una URL con seguimiento UTM se construye añadiendo a la URL de destino los parámetros
  UTM como query string (utm_source, utm_medium, utm_campaign y opcionalmente utm_term y
  utm_content), encadenados tras «?» y separados por «&»; se generan con creadores de URL
  como el Campaign URL Builder de Google, la extensión Google Analytics URL Builder de
  Chrome o UTMbuilder.net; implica etiquetar de forma consistente cada enlace antes de
  publicarlo para que Google Analytics atribuya correctamente su tráfico.
