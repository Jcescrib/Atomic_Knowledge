## Summary

Marco para escalar la generación de leads exprimiendo cualquier actividad Core Four en
tres palancas: More, Better, New.

## Core Components

1. **More** — sube el volumen al máximo. Rule of 100: 100 acciones primarias/día × 100 días.
2. **Better** — testing: 1 prueba/semana/plataforma, atacando el constraint (mayor drop-off);
   registra cada resultado para no empezar de cero.
3. **New** — nuevas ubicaciones → nuevas plataformas → nueva actividad Core Four.

## How to Apply

1. Pregúntate «¿qué impide hacer 10× lo que hago hoy?». Si nada → More.
2. Cuando More «rompe» (CAC sube), arregla el constraint → Better.
3. Cuando el retorno de More-Better cae por debajo de una opción nueva → New, en ese orden.

## Underlying Claims

Doblar inputs sube leads aunque no mejores nada; el constraint da el mayor ROI; el mercado
es mucho mayor de lo que parece (size-of-the-pie fallacy).

## Strengths

Simple, accionable y aplicable a cualquier canal; More y Better se refuerzan mutuamente.

## Limitations and Criticisms

New es más difícil en la práctica (por eso se deja para el final); exige medir throughput.

## Variants and Extensions

Combina canales: cada actividad Core Four potencia a las demás (contenido + ads, cold + contenido).
